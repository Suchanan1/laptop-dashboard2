# วิเคราะห์สเปกและราคาคอมพิวเตอร์โน้ตบุ๊ก (Web Dashboard)

โครงงานรายวิชา 01219482 Data Visualization

## ปัญหาที่แก้
ผู้ซื้อไม่ทราบว่าควรเลือกแล็ปท็อปสเปกใดให้คุ้มค่ากับงบประมาณ

## คำถามที่แดชบอร์ดตอบ
- Q1: RAM ส่งผลต่อราคามากน้อยแค่ไหน (Scatter Plot)
- Q2: แต่ละประเภทมีช่วงราคาต่างกันอย่างไร (Box Plot + Pie Chart)
- Q3: แบรนด์ไหนคุ้มค่าเมื่อสเปกเท่ากัน (Bar Chart, เทียบรุ่น Core i5 + RAM 8 GB, เลือกวัดด้วยค่ากลาง/ค่าเฉลี่ย/ค่าสูงสุดได้)
- Q4: ควรเลือกรุ่นไหนให้ตรงงานและอยู่ในงบ (ตัวแนะนำ 5 รุ่น แสดงรุ่นที่ราคาอยู่ในช่วง 70–100% ของงบ)

## ข้อมูล
Laptop Price (Kaggle) 1,303 รุ่น ราคาเป็นยูโร: `data/laptop_price.csv`

## วิธีใช้งาน
- **ดูแดชบอร์ด:** เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (ไม่ต้องติดตั้งอะไร ต้องต่อเน็ตเพื่อโหลดฟอนต์ ถ้าไม่มีเน็ตจะใช้ฟอนต์สำรอง)
- **สร้างใหม่จากข้อมูล:** `pip install pandas` แล้วรัน `python build_dashboard.py`

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แดชบอร์ดที่สร้างเสร็จแล้ว (HTML + CSS + JavaScript ไฟล์เดียว) |
| `template.html` | โค้ดหน้าเว็บและกราฟทั้งหมด (SVG วาดด้วย JavaScript) |
| `build_dashboard.py` | ทำความสะอาดข้อมูลด้วย Pandas แล้วฝังลงในหน้าเว็บ |
| `data/laptop_price.csv` | ข้อมูลดิบ |
