Q1 RAM กับราคาQ2 ประเภทQ3 แบรนด์Q4 แนะนำรุ่น

Q1RAM ส่งผลต่อราคามากน้อยแค่ไหน?

กราฟกระจาย: หนึ่งจุดคือ 1 รุ่น เส้นสีส้มคือราคากลาง สัญลักษณ์ ◇ คือราคาเฉลี่ย ของแต่ละขนาด RAM คลิกเพื่อดูรายละเอียดของแต่ละขนาด

ราคากลาง (median)◇ ราคาเฉลี่ย (mean)

Q2แต่ละประเภทมีช่วงราคาต่างกันอย่างไร?

Box plot: เส้นบางคือต่ำสุด–สูงสุด กล่องคือครึ่งกลางของรุ่นทั้งหมด ขีดสีส้มคือราคากลาง คลิกที่แถวเพื่อดูรายละเอียด

สัดส่วนประเภทโน้ตบุ๊กในตลาด

Q3แบรนด์ไหนคุ้มค่าเมื่อสเปกเท่ากัน?

เทียบเฉพาะรุ่น Core i5 + RAM 8 GB เท่ากัน (แสดงแบรนด์ที่มีอย่างน้อย 5 รุ่น) เลือกวัดค่าได้ 3 แบบ ค่ายิ่งต่ำ ยิ่งคุ้ม คลิกที่แท่งเพื่อดูรายละเอียด

Q4ควรเลือกรุ่นไหนให้ตรงงานและอยู่ในงบ?

เลือกงบและการใช้งาน ระบบจะแสดงรุ่นที่ราคาอยู่ในช่วง 70–100% ของงบ และเรียง 5 อันดับที่ให้สเปกต่อราคาดีที่สุด (เพิ่มงบ จะได้สเปกที่สูงขึ้น)

คะแนนสเปก = RAM + ระดับ CPU + มี SSD + น้ำหนักเบา ใช้เพื่อเรียงลำดับเท่านั้น ไม่ใช่ผลทดสอบประสิทธิภาพจริง
